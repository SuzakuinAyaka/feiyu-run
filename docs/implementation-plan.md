# 大肥鱼快跑实施计划

已确认：经典跑酷、像素鲸鱼女仆、海边跑道、即开即玩；可变高度单段跳、下蹲、加速、碰撞结束、重开、手机双按钮、本机最高分、后台自动暂停、可关闭音效、无背景音乐。

## 设计

参考图特征：蓝色长发、浅蓝发梢、女仆头饰、蝴蝶结、白围裙、蓝眼睛、深蓝鞋、鲸鱼尾巴。其余对象为礁石、漂流木、海鸥、海浪、跑道。

概念：鲸鱼女仆的海岸线变成一张可玩的街机游戏面板。整个页面以游戏为主体，操作说明为面板底部的说明纸条，没有营销区块。

用户随后明确覆盖入口设计：入口保持 Chrome 小恐龙式深灰背景、灰色像素角色与一句开玩提示，不展示大标题、营销区块或游戏外框；进入后切换彩色动漫角色与浅蓝海边场景。返回入口恢复像素风。统一系统中文无衬线字体，不依赖第三方字体服务。

design-taste-frontend 抽签：page-is-the-object，seed 436799332；保留面板式构图。文件夹预览、建筑照片、滚动场景与即时游戏需求不符，改为实际可玩 Canvas。ui-ux-pro-max 已运行 design-system，采用首屏操作、清晰焦点、触屏大按钮与减少动态效果；数据库建议的绿色及混乱拼贴与已确认蓝色海边风格冲突，不采用。游戏不为了满足营销页的四张图片、八个 DOM 入场动画指标增加无关内容。

## 顺序及验收

1. 先写 `tests/engine.test.js`，观察缺少引擎时失败，再实现 `src/engine.js`：跳跃、蹲伏、碰撞、暂停、加速、生成间距。测试以固定步长、固定随机输入运行，不宣称覆盖真人手感。
2. imagegen 依据用户参考图生成动作图，检查图像并保存 `assets/`；在素材说明记录生成方式与提示词。
3. 实现 `index.html`、`styles.css`、`src/game.js`、`src/render.js`：状态 UI、Canvas、输入、触屏、存储、音效、生命周期。
4. 增加 `tools/serve.mjs`、`tools/check.mjs`、`tools/build.mjs` 与 Pages 工作流，隔离发布产物。
5. 运行测试、语法检查、构建；实机浏览器检查桌面和手机、键盘与触屏、暂停重开、资源失败、项目子路径；查看截图并记录限制。
6. 检查实际 Diff 后创建本地 Conventional Commit；若远程连接可用，在已授权的 Pages 部署范围内发布。无法访问远程时保留完整产物并报告具体阻塞。
