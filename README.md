# 大肥鱼快跑 · Feiyu Run

在线游玩：[https://suzakuinayaka.github.io/feiyu-run/](https://suzakuinayaka.github.io/feiyu-run/)

蓝色鲸鱼女仆的海边跑酷小游戏。入口保留 Chrome 小恐龙式留白、小像素角色和开玩提示，支持手动深色/浅色切换；开玩后平滑进入彩色动漫海岸场景。

纯静态 HTML / CSS / JavaScript / Canvas，无后端，无运行时依赖，无外部字体或追踪请求。

## 本地运行

需要 Node.js 22 及以上，无须 `npm install`。

```powershell
npm run dev
```

打开终端输出的本地地址，默认 [http://127.0.0.1:4173](http://127.0.0.1:4173)。ES modules 需要 HTTP 服务，不能直接双击 HTML。

## 操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 开始 | 点按像素角色 / 空格 / ↑ / Enter | 点击屏幕空白处或角色 |
| 跳跃 | 空格 / ↑ / W；按住跳得更高 | 按住跳跃按钮，或点按游戏画面 |
| 下蹲 | 按住 ↓ / S；空中按下加速落地 | 按住下蹲按钮 |
| 暂停 / 继续 | P / Escape / 页面按钮 | 页面按钮 |
| 重开 | 空格 / Enter / 重开按钮 | 重开按钮 |

碰到礁石、漂流木或海鸥后本局结束，头发和尾巴不参与碰撞判定。速度逐渐增加且有上限。前 30 秒障碍生成间隔为 1.4～2.05 秒，之后逐渐缩短，到第 90 秒达到 1.15～1.7 秒并保持；最短间隔仍保留完整跳跃与下一次动作的准备时间。离开页面、打开操作说明或调整窗口时自动暂停，返回后需要主动继续。

右上角可切换入口主题和简体中文/英文；主题不跟随系统，主题与语言选择会记在当前浏览器。游戏中的语言按钮也可随时切换，不会重置本局分数。按钮、帮助、错误提示、页面标题和辅助技术提示均提供两种语言。

点击开始立即进入跑酷、计分并接收输入。「沿着海风，出发。」独立显示在上方空白区，清晰停留约 3 秒后淡出，不阻挡操作。跑动采用八帧换腿动作，以前进距离驱动步频，并辅以轻微重心起伏。最高分仅保存在当前浏览器的 `localStorage`；禁用存储时仍可游戏及切换主题、语言，但刷新后不保留选择。音效默认关闭，通过 Web Audio 即时合成，无背景音乐。减少动态效果设置会取消入场淡入、停止装饰漂移和额外身体起伏，保留必要的换腿与跑酷运动，出发文字仍静态显示约 3 秒。

背景增加太阳、低透明度椰树与随机分布的海星、扇形贝壳。椰树固定在世界坐标中，相邻间距 1250 单位，按前进距离的 18% 向后移动，不在可见区域循环瞬移；暂停后位置保持。树根锚定沙地表面，树冠使用绿色羽状叶片，树干为带分节纹理的暖棕色。椰树保持固定透明度，不因玩家或障碍接近而消失；先画椰树，再画障碍和角色，重叠时由前景正常遮挡，只在移出画面后停止绘制。海豚和虎鲸在远海跃出：海豚首次在本局第 18 秒出现，每 68 秒一次；虎鲸从第 52、74 秒开始，每 68 秒重复这两次跃起，不同时叠加。单次持续 6～7 秒，水平速度至多 20 个世界单位／秒。它们不参加碰撞，不使用或改变引擎随机数。海洋动物与波纹避开跑道上方 120 个世界单位，海星和贝壳避开跑道下方 48 个世界单位；减少动态效果时固定椰树并不显示跃出动物。高对比度的礁石、漂流木和海鸥仍是需要躲避的障碍。

最高分的键为 `feiyu-run.best`。入口右下角的「清空最高分」需要弹窗再次确认，仅删除该键，保留主题、语言及其他数据；取消或按 Escape 不修改记录。如果浏览器拒绝删除，会显示失败并保留记录。没有持久化存储时仅清空当前会话记录。

本局分数严格超过开局时的最高分后，当前分数显示蓝色呼吸光晕；平分不触发。暂停时冻结呼吸，结束后保留静态光晕，重开时重新判断。减少动态效果模式使用静态光晕。

## 验证与构建

沙滩海星和贝壳在每局开始时使用独立背景种子生成，位置、大小和朝向随机，一局内保持稳定并缓慢后移。透明度为 12%～17%，仅为装饰；不参与碰撞、不调用障碍使用的 `Math.random`。减少动态效果时停止装饰漂移。

移动端入口显示「点击屏幕即可开玩」，英文为「Tap the screen to play」；点击主题、音效、语言、帮助或确认弹窗不会误开局。桌面仍保留空格提示与键盘操作。

远海增加低幅度细波纹，缓慢漂移与起伏，保留跑道附近的平色区域。天空海鸥群使用两笔浅线轮廓，每群 3～7 只，首次约 7～12 秒后从右侧进入；后续间隔随机为 24～52 秒，每群以随机的 14～26 世界单位／秒匀速向左飞行。生成后形状和透明度固定，完全离开左侧才移除，不淡入淡出、不参与碰撞。短横屏天空空间不足或启用减少动态效果时不绘制鸟群。

## GitHub Pages

仓库内已配置 `.github/workflows/pages.yml`。将本项目上传至你拥有的 GitHub 仓库后，在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。推送到 `master` 或 `main` 会先测试、检查和构建，再发布 `dist/`；也可以手动运行工作流。

项目站点地址通常是 `https://<用户名>.github.io/<仓库名>/`。资源全部使用相对路径，支持仓库子路径部署。实际发布地址以 Actions 的部署结果为准。

## 目录

- `src/engine.js`：状态、物理、障碍、计分及碰撞。
- `src/game.js`：输入、UI、生命周期、存储、音效。
- `src/render.js`：入口像素角色、游戏场景与动漫动作图绘制。
- `src/animation.js`：按距离计算八帧步态与重心起伏。
- `src/scenery.js`：远景布局、低频海洋动物和装饰绘制，与物理引擎隔离。
- `src/i18n.js`、`src/preferences.js`：中英文文案和手动偏好保存。
- `assets/`：本地角色动作图与图标。
- `tests/`：核心引擎测试。
- `tools/`：无依赖服务、检查及构建工具。
- `docs/`：调研、实现方案、素材来源与验证记录。
